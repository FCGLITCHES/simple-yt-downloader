GetVideosLocally 3.1.0 release scope

Smaller installs, cleaner uninstalls.

Reduce the Windows package without removing active download capabilities, and make uninstall remove app-owned files while treating downloaded media as user-owned content.

1,165 MB current unpacked installer
394 MB binary folder duplicated in package
98 MB unused ffplay executable

Goal and scope

Change Windows installer packaging and uninstall behavior only. Preserve the current runtime architecture and download workflows. Do not delete a user's downloaded videos without a clear uninstall confirmation.

Storage ownership

  • Installed application files belong to the installer and are always removed.
  • Chromium caches, cookies, logs, queues, settings, and update artifacts are app-owned and are removed on uninstall.
  • %APPDATA%\GetVideosLocally\downloads contains user-owned media. The uninstaller asks whether to delete it and defaults to keeping it.

Implementation

  1. Replace broad package inclusion with an explicit allowlist, ensuring bin, assets, and public are bundled exactly once.
  2. Stop shipping and updating ffplay; retain ffmpeg, ffprobe, yt-dlp, and Node.
  3. Replace stale SimplyYTD uninstall hooks with GetVideosLocally cleanup for shortcuts, startup entries, app registry entries, app data, local cache, and temporary update artifacts.
  4. Add static packaging tests and uninstall-script tests so duplicate payloads and stale cleanup names cannot return.
  5. Update architecture and release documentation with storage ownership and uninstall behavior.

States and fallback

  • Default: preserve downloads and remove everything else.
  • Confirmed removal: delete downloads with the remaining app data.
  • Locked file or denied permission: continue uninstalling other entries; Windows may retain only the locked target.
  • Existing installations using the old SimplyYTD identifiers are cleaned for backward compatibility.

Acceptance criteria

  • No packaged resource appears both inside app.asar and as an extra resource.
  • ffplay.exe is absent and media probing/conversion dependencies remain present.
  • Current and legacy shortcuts, startup entries, and registry keys are removed.
  • App-generated data is removed; downloads survive unless deletion is confirmed.
  • Targeted tests and the relevant existing Node test suite pass.
