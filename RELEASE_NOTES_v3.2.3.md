# GetVideosLocally v3.2.3

## HDR, Download Accuracy, And Interface Polish

- HDR is now off by default for fresh settings, with saved and per-download opt-in controls.
- Added explicit 8K (4320p) selection while keeping every lower quality strictly capped.
- Corrected transfer-speed reporting so tiny initial samples no longer pin the displayed rate.
- Flattened Advanced Options, integrated subtitle controls, and strengthened modal typography.
- Redesigned the cookie importer and support prompt with clearer, flatter actions.
- Compacted What’s New into a two-column view with visible close and Got it controls.

Downloaded media remains protected during uninstall, while application-created settings, caches, logs, queues, shortcuts, startup entries, and updater artifacts are cleaned up.
