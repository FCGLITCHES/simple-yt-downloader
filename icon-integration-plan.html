Canonical asset

public/Logo1.ico owns application branding. It contains 16, 24, 32, 48, 64, 128, and 256 pixel images. macOS and Linux retain their platform-specific icon sets.

Implementation

  1. Brand the packaged Windows executable through the shared post-package resource editor.
  2. Use the canonical ICO for NSIS, Electron windows, and tray icons.
  3. Set the Windows AppUserModelID to the package app ID.
  4. Apply the same icon and package version to portable executables.
  5. Add regression checks for every icon ownership boundary.

Acceptance criteria

  • The built EXE no longer extracts to the Electron logo.
  • Desktop and Start Menu shortcuts inherit the branded EXE icon.
  • The installer, uninstaller, taskbar, windows, and tray use the brand.
  • Installed registration reports version 3.1.0 with a branded icon.
  • Source tests, icon structure checks, build, install, and Windows UI checks pass.
